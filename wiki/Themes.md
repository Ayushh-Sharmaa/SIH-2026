## 2. Terminology & Display Standards

To maintain consistency across UI components, search filters, and profile forms, the platform adheres to strict terminology rules:

* **Approved User-Facing Terms**:
  * **Theme** (singular)
  * **Themes** (plural)
  * **Primary Theme** (main problem statement focus)
  * **Secondary Theme** (optional backup problem statement)
  * **Themes & Links** (profile section header)
* **Banned Terms**:
  * Do not use "Track" or "Tracks" in user-facing UI copy (use "Theme" instead).
  * Do not refer to "18 themes" — the catalog is strictly 17 official themes.

---

## 3. Theme Allocation Rules

1. **Student Track Profiling**: During onboarding, students can select up to 3 theme interests to indicate problem areas they want to solve.
2. **Team Registration**:
   * Every team **must** select one **Primary Theme**.
   * Teams may optionally select one **Secondary Theme**.
3. **Filtering by Theme**:
   * The **Browse Teammates** directory enables filtering by theme interests.
   * The **Browse Teams** directory enables filtering by primary domain category.
